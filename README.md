# TG Game Hub 🎮

An interactive arcade gaming hub and Telegram Mini App designed for fast, responsive web & mobile minigames.

---

### Features
- 🕹️ **Arcade Minigames** — Fluid, mobile-first responsive gameplay
- 🏆 **Leaderboards** — Real-time highscores and rankings
- 🌐 **Telegram Mini App** — Seamless launch directly inside Telegram
- ⚡ **Modern Stack** — React, Vite, TypeScript & Node.js
